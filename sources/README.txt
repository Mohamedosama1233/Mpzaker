حط هنا ملفات المصادر (txt أو md) اللي عايز مذاكر يجاوب منها بس.

- سمّي كل ملف باسم المادة الأول، مثلًا: فيزياء - الباب الأول.txt
  (الاسم بيساعد الموقع يختار المصدر الصح لمادة الطالب).
- افصل بين الفقرات بسطر فاضي.
- ملفات اسمها بتبدأ بـ README مش بتتقرا.
- استخدم مواد الوزارة الرسمية، أو ملخصات إنت كاتبها، أو مواد معاك إذن باستخدامها.
