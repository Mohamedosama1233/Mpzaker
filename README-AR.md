# نشر موقع مذاكر

## اللي هتحتاجه (كله مجاني للبداية)
- حساب على GitHub
- حساب على Vercel (سجّل بحساب GitHub)
- حساب على Upstash (للداشبورد)
- مفتاح OpenRouter **جديد**

## الخطوات

### 1. المفتاح
- أي مفتاح اتبعت في شات قبل كده، احذفه من openrouter.ai/keys واعمل واحد جديد.
- المفتاح هيتحط في Vercel بس، ومش هيتكتب في أي ملف.

### 2. الموديل
- افتح openrouter.ai/models واختار موديل بيقبل صور (Input: image) وقوي في العربي.
- انسخ اسمه زي ما هو (مثال على الشكل: `provider/model-name`)، هتحطه في خانة `MODEL`.
- الموديلات المجانية فيها حد يومي وبيتقسم على كل الطلاب. لو الطلاب كتروا، اشحن رصيد صغير واختار موديل مدفوع رخيص.

### 3. المصادر
- حط ملفات txt في فولدر `sources` (اقرأ README جواه).

### 4. الداشبورد (Upstash)
- من upstash.com اعمل قاعدة Redis مجانية.
- من صفحة القاعدة انسخ `UPSTASH_REDIS_REST_URL` و `UPSTASH_REDIS_REST_TOKEN`.

### 5. الرفع
- اعمل Repository جديد على GitHub وارفع فيه كل ملفات المشروع (Add file → Upload files).
- من Vercel اضغط Add New → Project واختار الـ Repository.
- قبل ما تضغط Deploy، افتح Environment Variables وضيف:

| الاسم | القيمة |
|---|---|
| `OPENROUTER_API_KEY` | المفتاح الجديد |
| `MODEL` | اسم الموديل من الخطوة 2 |
| `ADMIN_PASSWORD` | كلمة سر قوية للداشبورد |
| `UPSTASH_REDIS_REST_URL` | من الخطوة 4 |
| `UPSTASH_REDIS_REST_TOKEN` | من الخطوة 4 |

- اضغط Deploy.

### 6. الاستخدام
- موقع الطلاب: `https://اسم-مشروعك.vercel.app`
- الداشبورد: `https://اسم-مشروعك.vercel.app/admin.html` وتدخل بكلمة السر.
